SimpleEqualizer

macOS では音量を変えられない出力先でも、音量を変えて、10 バンドのイコライザーを掛けられます。

ダウンロード GitHub で見る

macOS 27 以降 · Apple シリコンの Mac · 無料(MIT ライセンス)

何ができるか

Mac から光デジタル出力(USB SPDIF Adapter)などを通してスピーカーに音を出すときは、macOS では音量を変えられず、スピーカーから最大音量のまま音が出ます。SimpleEqualizer は、その音量をアプリの側で変えるための、メニューバー常駐アプリです。イコライザーも掛けられます。

  • 音量と消音メニューバーのポップアップで音量を変えます。音量は出力先ごとに覚えます。
  • 音量キーキーボードの音量キー(上げる、下げる、消音)を、ふだんどおりに使えます。
  • 10 バンドのイコライザー31 Hz〜16 kHz を、−10〜+10 dB の間で、0.5 dB ずつ変えられます。
  • ラウドネス音量を下げるほど低音と高音を持ち上げ、小さな音でも聞こえやすくします。
  • プリセットイコライザーの設定に名前をつけて保存し、切り替えられます。書き出しと読み込みもできます。
  • 日本語と英語画面は、日本語と英語に対応しています。

使う前に

起動する前と、終了する前に、スピーカー側の音量を下げてください。

アプリが音量を下げているのは、アプリが動いている間だけです。終了したとき、「音声の加工」を切ったとき、アプリが落ちたときは、音が加工なしの最大音量に戻ります。初めて使うときの音量は 100(元の音量のまま)です。起動したあと、ポップアップで下げてください。

入れ方

  1. Releases から、SimpleEqualizer-<版>.dmg をダウンロードして開きます。
  2. SimpleEqualizer を「Applications」フォルダへドラッグします。

はじめて開くとき

このアプリは、Apple の公証を受けていません(作者が Apple の有料の開発者プログラムに入っていないため)。そのため、はじめて開くときと、新しい版に入れ替えたときに、macOS に止められます。次の手順で開いてください。

  1. 「アプリケーション」フォルダの SimpleEqualizer をダブルクリックします。
  2. 「"SimpleEqualizer.app" は開いていません」と出たら、「完了」を押します(「ゴミ箱に入れる」は押さないでください)。
  3. システム設定を開き、「プライバシーとセキュリティ」を選びます。
  4. 下のほうの「セキュリティ」の欄に、「お使いの Mac を保護するために "SimpleEqualizer.app" がブロックされました。」と出ています。その右の「このまま開く」を押し、Mac のパスワードを入れます。
  5. もう一度確かめる画面が出たら、「このまま開く」を押します。

許可を出す

  • システム音声の録音: 音を加工するために要ります。初めて起動したときに求められるので、許可してください。
  • アクセシビリティ: キーボードの音量キーを使うために要ります。

ポップアップ、イコライザー、プリセット、設定の使い方は、README をご覧ください。
