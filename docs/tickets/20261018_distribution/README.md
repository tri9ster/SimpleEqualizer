# 配布 チケット一覧(2026-10-18)

GitHub の公開リポジトリで、ソースとビルド済みのアプリを配るための作業(仕様書 1.1、7.1)。
決めたことは `private/20261018_distribution.md` にある(Git に入れない。2026-11-08 に `input/` から名前を変えた)。

- リポジトリは公開する。配る形は、ソースとビルド済みのアプリの両方。
- 画面と README は、日本語と英語。
- 利用許諾は MIT。
- Apple Developer Program には、いまは登録しない。ほかの人の Mac では警告が出ることを前提にし、README に書く。

## 作業順序

```
TICKET-001 公開前の点検(Git の履歴と docs)
    ├─ TICKET-002 配布物に含めるファイルの整理
    └─ TICKET-003 利用許諾の確認と LICENSE
TICKET-004 最適化ありのビルド(Release)
    ├─ TICKET-005 画面の英語対応
    └─ TICKET-006 署名の方式と、配布物の作り方
           └─ TICKET-007 README(英語と日本語)
                  └─ TICKET-008 置き場所に移したあとの確認(開発が全部終わってから)
                         └─ TICKET-009 GitHub への公開とリリース
```

- 001 を最初にする理由: 履歴を書き換えることになると、そのあとの作業のやり方(コミットの作者など)が変わる。早く決めておく。
- 004 を 005、006 の前にする理由: 配布物は Release で作る。Release で問題が出たら、先に直しておきたい。
- 005(画面の英語対応)は、利用者の指示で、リリースの前に行う(2026-10-18)。006、007 を先に進める。
  README の英語版は、画面が日本語だけの間は、そのことを書いておく。
- 008 を公開の前にする理由: 配布物と同じアプリを、自分の Mac で、ふだんどおりに使えることを確かめてから公開する。
