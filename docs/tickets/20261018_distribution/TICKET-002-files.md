# TICKET-002: 配布物に含めるファイルの整理

## 概要

公開するリポジトリに残すファイルと、消すものや Git から外すものを決める。

## 現状

2026-10-18 時点。未着手。

- `input/memo.md` は Git に入っていない(利用者のメモ)。`input/README.md` と `input/20261018_distribution.md` は入る。
- `docs/archive/` に、試作のころの、ビルドしないコードがある。
- `tools/` に、開発のときだけ使うスクリプトがある(出力先の調査、アイコンの作成)。
- `Config/Project.xcconfig` に、「配布しないので、サンドボックスは使わない」という古い説明がある。

## 対応方針・作業手順

1. ファイルごとに、残す・消す・Git から外すの案を表にして、利用者に確かめる。
   - 案: `docs/`(開発の記録)、`tools/`、`design/` は残す。開発の経過として読めるため。
   - `input/` は、利用者のメモを公開するかを決める。
2. `.gitignore` を見直し、ビルドの生成物、`Config/Signing.xcconfig`、個人の Xcode の設定が入らないことを確かめる。
3. 古い説明を直す(`Config/Project.xcconfig` など)。

## 影響ファイル

- `.gitignore`、`Config/Project.xcconfig`、`input/`、`docs/README.md`(目次)

## 実施結果

### 残すファイル(2026-10-18、利用者が案のとおりに決めた)

TICKET-001 で消したものを除き、いま Git に入っているファイルは、すべて残す案とする。

| フォルダ | 中身 | 案 | 理由 |
| --- | --- | --- | --- |
| `SimpleEqualizer/`、`SimpleEqualizer.xcodeproj/` | アプリのコードと、Xcode のプロジェクト | 残す | ソースとして配る |
| `Core/` | 音を出さずに確かめられる処理と、そのテスト(C の音声処理を含む) | 残す | 同上 |
| `Config/` | ビルドの設定、許可の説明文、署名の設定の見本 | 残す | ソースからビルドするのに要る。`Signing.xcconfig` は Git に入らない |
| `design/` | アイコンの元データ(SVG) | 残す | アイコンを作り直すのに要る。出どころは TICKET-003 で確かめる |
| `assets/readme/` | README に入れるイラスト(SVG。2026-11-08 に足した) | 残す | README で表示する |
| `tools/` | 出力先を調べるスクリプト、アイコンを作るスクリプト | 残す | 開発のときに使う。アプリには入らない |
| `docs/` | 仕様書、設計、開発の記録、チケット、試作のコード(`archive/`) | 残す | 何をなぜそう作ったかを読める。Claude Code で開発した記録になる |
| `input/` | `README.md` と配布の方針 | 残す | 開発の進め方(人が置く入力と、Claude が書く記録を分ける)が分かる |
| `CLAUDE.md` | Claude に向けた開発の決まり | 残す | TICKET-001 のとおり |

### 直したこと

- `.gitignore` に、`input/memo.md`(利用者のメモ)と `.DS_Store` を足した。
  メモは、これまで「Git に入れていないだけ」で、まとめて登録する操作をすると入るおそれがあった。
- `Config/Project.xcconfig` の「配布しないので、サンドボックスは使わない」を、いまの方針に合わせて直した。

### 確かめたこと

- `git status --ignored` で、外れているのは `Config/Signing.xcconfig`、`Core/.build/`、`input/memo.md` だけ。
- このリポジトリを別の場所へ取得し直した状態で、Xcode のプロジェクトを開ける(`xcodebuild -list` でスキームが見える)。
  ビルドはしていない(別の場所でビルドすると、同じ識別子のアプリが macOS に2つ登録される。`failures.md`)。
- `Signing.xcconfig` がない状態で、ほかの人がビルドできるか(署名をどうするか)は、TICKET-006 で決める。
