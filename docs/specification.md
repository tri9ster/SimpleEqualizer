## 1. 背景と目的

Mac から USB-C → S/PDIF(光デジタル)のケーブルを通して、SONOS Ray に音を出している。
この構成では、macOS の音量調整(キーボードの音量キー、メニューバーのスライダー)が効かない。
光デジタル出力が「音量調整の機能を持たない出力装置」として認識され、macOS が音量を変えられないためである。

SimpleEqualizer は、Mac の中で音声信号そのものを加工して、次のことを実現する。

1. 音量を変える(音量キーも使える)。
2. 10 バンドのイコライザーと、ラウドネスで音質を整える。
3. イコライザーの設定に名前をつけて保存し、あとから呼び出す。

加工は、光デジタル出力に限らず、macOS のいまの出力先(内蔵スピーカーなど)に掛かる。

はじめは自分の Mac だけで使うつもりで作った。2026-10-18 に、GitHub で公開し、ほかの人も使えるようにすることにした(7.1)。

## 2. 対象環境

| 項目 | 内容 |
| --- | --- |
| Mac | Mac mini(Apple シリコン) |
| OS | macOS 27 |

## 3. 実現方法

### 3.1 比べた案

| | 案A: Core Audio のプロセスタップ | 案B: 仮想オーディオ装置 | 案C: SONOS をネットワーク経由で操作 |
| --- | --- | --- | --- |
| しくみ | システム全体の音を取り出して元の音を消し、加工した音を出力先へ流す | 音量調整つきの仮想装置を既定の出力にし、そこから受け取った音を加工して流す | 音声には触らず、SONOS へ命令を送って音量と音質を変える |
| イコライザー | 自由に作れる | 自由に作れる | 低音・高音・ラウドネスだけ |
| 音量キー | アプリが受け取る(アクセシビリティの許可) | そのまま効く | アプリが受け取る |
| 追加インストール | なし | ドライバーが要る | なし |
| 音質 | 音量を下げた分だけ、信号の細かさが減る | 同左 | 落ちない |

### 3.2 決定

**案A で作る(2026-10-12 決定)。** 音量、イコライザー、保存と呼び出しを、追加インストールなしで満たせる。

- 案B は、ドライバーの自作と保守の負担が、音量キーがそのまま効く利点を上回る。
- 案C は、10 バンドのイコライザーを満たせない。音質を落とさずに音量を変えられるので、案A と組み合わせる価値がある。
  次の段階の候補とする(継続の課題)。

### 3.3 実機で分かったこと

くわしくは `research/Prototype_Result.md`、`research/OutputDevices_Survey.md`、`failures.md`。

- 案A の API(`AudioHardwareCreateProcessTap`)は、macOS 27 と USB SPDIF Adapter で動く。元の音は消え、加工した音だけが出る。
- 音の遅れは、動画の視聴で気にならない(装置が申告する遅れとバッファの合計は 15.8 ミリ秒)。
- アプリを終了したとき、異常終了したときは、音が元の経路(加工なし)に戻る。
- USB SPDIF Adapter には音量調整の機能がなく、24 ビットで出力している(16 ビットより、音量を下げたときの音質の低下が小さい)。
- 再生する音源のサンプリング周波数が変わる(44.1 kHz と 48 kHz)と、作り直さない経路では音がとぎれる。
  周波数が変わったら、加工の経路を作り直す(4.5)。
- ケーブルを差し直すと、装置の番号が変わり、前の経路は動いていても音を取り出せなくなる。差し直されたら、経路を作り直す(4.5)。

## 4. 機能

### 4.1 音量

- 0〜100 の範囲で変える。100 で元の音量、0 で無音。初期値は 100(アプリを使う前より大きくなることはない)。
- 音量の数値は、0〜1 に直した値の3乗を倍率にする(50 で約 −18 dB、30 で約 −31 dB、10 で −60 dB)。
- 保存してあった音量が使えないとき(読めない、足りない、範囲の外、ファイル全体が読めない)は、30 で始める。
  前に小さくして使っていたかもしれないので、壊れた設定で大きな音を出さないため。
- 変える方法は、メニューバーのスライダー、消音、キーボードの音量キー(4.6)。
- 音量と消音は、出力先ごとに覚える。初めて使う出力先は、音量 100、消音なしで始まる。

アプリによる音量調整には、有効と無効がある。

- 出力先の装置の種類で、自動で決まる。利用者が切り替える設定は持たない(切り替え忘れで最大音量が出るのを防ぐ)。
  - 自分で音量を変えられない装置(USB SPDIF Adapter など): 有効。アプリが音量を変える。
  - 自分で音量を変えられる装置(内蔵スピーカーなど): 無効。アプリは音量を変えず、macOS の音量で変える。
    アプリの音量、消音、ラウドネス、音量キーは働かない(音量が二重に掛かるのを防ぐ)。
- 装置が音量を変えられるかが分からないときは、有効として扱う。

### 4.2 イコライザー

- 10 バンド: 31 / 62 / 125 / 250 / 500 / 1k / 2k / 4k / 8k / 16k Hz。各バンドは −10〜+10 dB を 0.5 dB 刻みで変える。
- 入・切を1操作で切り替えられる(聴き比べ用)。
- 動かしている間も、音切れなく、すぐに音に反映する。
- イコライザーの設定は出力先に共通で、出力先ごとには覚えない。出力先に合わせるときは、プリセットを切り替える。

リミッター:

- 増幅で音が割れないよう、出力の直前で、上限(元の信号の最大値)を超えた分を抑える。
  出力は、どんな場合も上限を超えない。
- 音量を下げている間は、増幅しても上限を超えにくい。働くのは、主に音量が 100 に近いときである。
- 抑えているときは、イコライザーのウィンドウに説明を出す。

音量調整が無効の出力先で、増幅したとき:

- いつも元の音量なので、増幅するとリミッターが働き続け、音がつぶれる。
  そこで、増幅した分だけ、全体を自動で下げる。小さくなった分は、macOS の音量で上げる。
- 下げる量は、となり合うバンドの山の重なりを含めて見積もる(全部を +10 dB にすると、約 +15.5 dB 増幅する)。
  下げるだけの設定なら、何も下げない。
- この「自動で下げる」は、切にできる(初期値は入)。スピーカーごとに音量を合わせて音質を聴き比べるときに使う。
  切のときは、リミッターが働くことがある。

### 4.3 ラウドネス

小さい音量で聞こえにくくなる低音と高音を、音量に応じて持ち上げる。イコライザーとは別に働く。

- 効き具合を、強さ(0〜100)で決める。0 で効かない。初期値は 0。
- 入・切のスイッチを持つ(初期値は入)。切にしても強さは覚えていて、入に戻すとその強さで効く。切の間は、強さのスライダーを動かせない(2026-10-20、利用者の指示で変えた)。
- 補正量は、強さに比例する。強さ 100 での上限は、低音(100 Hz より下)+15 dB、高音(8 kHz より上)+6 dB。
- 音量 100 で補正なし。音量を下げるほど補正が増え、音量 50 あたり(18 dB 下げたところ)で上限に達する。
  それより下げても増えない(小さい音量で効きすぎないようにする)。
- 補正は、いつも音量による減衰より小さい。ラウドネスだけで、元の音量を超えることはない。
- 消音の切り替えでは、補正量は変わらない。イコライザーを切にしても、ラウドネスは効いたままにする(ラウドネスのスイッチは別)。
- 音量調整が無効の出力先では使えない(補正量を決める音量がないため)。
- 補正量は SONOS Ray で聴いて決めた。ほかの出力先では、強さで合わせる。
- スピーカー本体にもラウドネスの設定がある場合は、二重に掛かる。アプリ側を使うときは、スピーカー側を切る。

| 音量 | 強さ 50(低音 / 高音) | 強さ 100(低音 / 高音) |
| --- | --- | --- |
| 90 | +1.1 / +0.5 dB | +2.3 / +0.9 dB |
| 70 | +3.9 / +1.5 dB | +7.7 / +3.1 dB |
| 60 | +5.5 / +2.2 dB | +11.1 / +4.4 dB |
| 50 以下 | +7.5 / +3.0 dB | +15.0 / +6.0 dB |

### 4.4 プリセット

- いまの 10 バンドの値に名前をつけて保存し、一覧から呼び出す。メニューバーのポップアップからも選べる。
- プリセットに含めるのは、10 バンドの値だけ。音量、消音、ラウドネスの強さと入・切、イコライザーの入・切は含めない。
- はじめからあるのは「フラット」(すべて 0 dB)だけ。「フラット」は、上書き、名前の変更、削除ができない。
- 選んでいるプリセットと値が違うときは、名前に `*` をつける(保存していない変更がある印)。
- 操作: 保存(上書き)、別名で保存、変更を戻す、フラットに戻す、名前の変更、削除、書き出し、読み込み。
- 名前: 同じ名前は作れない。30 文字まで。空の名前は使えない。
  前後の空白を取り、続いた空白や改行を空白1つにまとめ、見えない文字を取り除いてから、調べて保存する。
- 「フラット」の名前は、画面の言語で変わる(英語では Flat)。どの言語の「フラット」の名前も、利用者のプリセットには使えない
  (言語を切り替えたときに、名前が重ならないようにするため)。
- 確かめる画面を出す場面:
  - 保存していない変更があるときに、別のプリセットを選ぶ。ポップアップで選んだときは、ポップアップの中の確かめるカード(5.1)で確かめる。
  - すべて 0 dB の値で上書きする。
  - 削除する。削除したあとは「フラット」に切り替わる(`*` はつかない)。音を下げる設定を消すと音が大きくなるので、そのことを伝える。
  - 保存していない変更があるまま書き出す(書き出されるのは、保存してある値)。
- 書き出しと読み込み(バックアップ用):
  - 書き出しは、「フラット」を除く全部のプリセットを1つのファイルに書く。
  - 読み込みは、いまの一覧に足す(置き換えない)。同じ名前があるときは、読み込む側の名前に番号をつける(「映画 2」)。
    読み込んだだけでは、音は変わらない。
  - 読み込めるのは、1つのファイルにつき 500 件まで、2 MB まで。

### 4.5 出力先との連動

- 加工の対象は、macOS のいまの出力先。どの出力先にも、同じ加工(イコライザー、ラウドネス)を掛ける。
  出力先が変わったら、対象も一緒に切り替える。出力先ごとに「加工しない」を選ぶ機能は持たない。
- 出力先は、ポップアップの選択パネルでも選べる(5.1)。選ぶと、macOS の出力先そのものが切り替わる。
  加工の対象は、macOS のメニューで切り替えたときと同じしくみで追いかける。切り替える前に、確かめる画面は出さない。
- 一覧に出すのは、macOS の出力先になれる装置(アプリが音を取り出すために作った装置は出さない)。名前の順に並べる。
  扱えない形の装置も出し、名前のあとに「(加工できません)」とつける。
- 扱うのは、出力が1本、2チャンネルの出力先。それ以外の出力先では、音声に触らず、扱えない理由を画面に出す。
  AirPlay は、利用者が試してイコライザーが効いた(くわしくは確かめていない)。Bluetooth は確かめていない。

切り替えた瞬間に、加工なしの最大音量が出ないための決まり:

- 音量調整が有効な出力先(自分で音量を変えられない装置)の経路は、いまの出力先でないあいだも持ったままにする。
  戻した瞬間から、加工された音が出る。
- 音量調整が無効な出力先の経路は、いまの出力先になったときに作る。作る間(0.15 秒ほど)は加工なしの音が出るが、macOS の音量が効いている。
- 装置が抜かれたら、その経路を片付ける。差し直されたら、作り直す(作る間の 0.15 秒ほどは、加工なしの音が出る)。
- サンプリング周波数が変わったら、経路を作り直す。新しい経路を作ってから前の経路を片付け、前の経路の音は先に消す。
  作り直す間(0.7 秒ほど)は無音になる。新しい経路を作れなかったときは、前の経路を残す。
- 経路を作れなかったときは、1 秒後にもう一度試す。それでもだめなら、出力先の顔ぶれが変わったときと、30 秒ごとに試し直す。

スリープ:

- スリープの間は、経路に触らない(装置を始めようとすると、エラーになり、呼び出しが 6 秒ほど戻らない)。
  復帰すると、持っていた経路は、そのまま動き出す。

### 4.6 音量キー

- キーボードの音量キー(上げる、下げる、消音)で、アプリの音量を変える。アクセシビリティの許可が要る。
- 1回で 1/16 ずつ変わる(macOS と同じ刻み)。Option + Shift を押しながらだと 1/64 ずつ。
  スライダーで決めた、刻みの途中の音量からは、となりの刻みへ動く。
- 消音しているときに上げる・下げるを押すと、消音を解く。消音のキーは、押し続けても1回だけ切り替わる。
- アプリが受け取るのは、加工していて、いまの出力先の音量調整が有効なときだけ。それ以外は macOS に任せる。
- 受け取ったキーは、macOS に渡さない。押したときは、音量の表示(5.4)を出す。
- 設定で、使わないようにできる(初期値は使う)。使わないときは、キーの受け取りを外す。

### 4.7 常駐と起動

- メニューバーに常駐する。Dock にはアイコンを出さない。
- 起動したら、自動で加工を始める。始める瞬間は、倍率を 0 からなめらかに上げる。
- ログイン時に起動する設定を持つ(初期値は切。macOS のログイン項目に登録する)。
- 「音声の加工」を切ったとき、終了したとき、異常終了したときは、音は加工なしの元の状態(最大音量)に戻る。
  切る操作と終了は、そのことを伝えて確かめてから行う。
  ポップアップのボタン(稲妻、✕)で行うときは、ポップアップの中の確かめるカード(5.1)で確かめる。⌘Q とほかのアプリからの頼みは、ダイアログで確かめる。
  終了は、ポップアップのボタン、⌘Q、ほかのアプリからの終了の頼みの、どれでも確かめる。
  加工していないとき(音量は変わらない)と、ログアウト・再起動・システム終了のとき(確かめると macOS の操作が止まる)は、確かめない。

## 5. 画面

画面の文言には、特定の機材の名前を書かない(「スピーカー側の音量」のように書く)。
画面の言語は、日本語と英語。macOS の言語の設定に合わせて切り替える(2026-10-18 決定)。
日本語でも英語でもない言語の Mac では、英語で出す(2026-10-26、利用者の判断)。
設定のウィンドウで、システムの設定に合わせるか、日本語か、英語かを選べる(2026-10-27、利用者の指示。5.3)。
許可を求めるときの説明文(8章)も、日本語と英語を用意する。
確かめる画面の「進める」ボタンは、Return キーでは押せない。Esc でキャンセルできる。ポップアップの中の確かめるカード(5.1)も同じ。

### 5.1 メニューバーのポップアップ

メニューバーのアイコンを押すと開く。ふだんの操作は、ここで済む。
関係する項目を、角の丸い枠にまとめる(音量の枠と、音質の枠)。ボタンは、文字ではなく macOS 標準のアイコンにする(2026-10-19、利用者のデザイン)。

上から順に:

- 音声の加工の入・切(稲妻のアイコン)と、出力先のタイル(いまの出力先を文字列で出す。押すと選択パネルが開き、選ぶと macOS の出力先を切り替える。4.5)。
  加工を切るときは、加工なしの最大音量に戻ることを、ポップアップの中の確かめるカードで伝える。
- 音量の枠: 消音(スピーカーのアイコン。消音中は斜線つき)、音量のスライダー、その右に音量の数値。消音の間は、スライダーを動かせない。
  スライダーを動かせないときは、右の数値も薄く出す。
  音量調整が無効の出力先では動かせず、「macOS の音量で変えます」と出す。
- 音質の枠:
  - ラウドネスの入・切、強さのスライダー(0 で効かない。5 刻み)、その右に強さの数値。ラウドネスが切の間は、スライダーを動かせない。
  - イコライザーの入・切、イコライザーを開く、プリセットの選択。
- 設定(歯車のアイコン)と、終了(✕ のアイコン。加工中は、ポップアップの中の確かめるカードで確かめてから終える)。

ボタンの決まり:

- 入・切のあるボタン(加工、消音、ラウドネス、イコライザー)は、色ではなく、アイコンの絵で入・切を表す(2026-10-20、利用者の指示)。
  絵は下の表。
- アイコンだけのボタンには、マウスを乗せたときの説明(いまの状態と、押すとどうなるか)と、読み上げ用の名前をつける。
- 押すと、ボタンが少し縮んで戻る。入・切が変わると、絵が移り変わる(斜線やバッジがつく・消える)。
  入・切のないボタン(イコライザーを開く、終了)は、押すとアイコンが弾む。設定の歯車は、1回転してから設定の画面を開く(画面が開くとポップアップが閉じるため。2026-10-19・20、利用者の指示)。
- 左端のボタン(音声の加工、消音、ラウドネス、イコライザー、設定)は、縦の中心をそろえる(2026-10-20、利用者の指示)。
- 「音量」「ラウドネス」「イコライザー」の見出しの文字は出さない。数値の右端と、タイル(出力先、プリセット)の右端をそろえる(2026-10-20、利用者の指示)。
- ボタン、スライダー、タイルには、マウスを乗せたときの説明をつける。

選択パネル(出力先、プリセット。2026-10-20、利用者の指示):

- 出力先とプリセットは、プルダウンではなく、いまの値を文字列で出すタイルにする。押すと、ポップアップの中で選択パネルが開く。
- 開くとき(約 250〜300 ms): ほかの中身(知らせ、音量の枠、音質の枠の残り、設定と終了)が、上から順に少しずつずれて消える
  (不透明度 0、ぼかし、少し縮む。枠と欄の背景はぼかさない。ぼかすと一瞬白く光るため)。少し遅れて、押したタイルが、いちばん上へ移りながらパネルの大きさに広がる。
  移る間は、タイルとパネルの中身が重なって入れ替わる。
- パネルは、幅がポップアップいっぱい、高さは選択肢に合わせる。ポップアップの大きさは変えない。選択肢が入りきらないときは、中でスクロールする。
- 選択肢を押すと、閉じてから選ぶ(プリセットは、保存していない変更があれば、パネルが確かめるカードに移り変わる)。
  見出し(いまの値)を押すか Esc で、選ばずに閉じる。閉じるときは、逆の順に戻る。
- 「視差効果を減らす」が入の Mac では、ぼかし・縮み・移動をせず、薄くなって入れ替わるだけにする。
- イコライザーのウィンドウのプリセットは、プルダウンのまま。

| ボタン | 入 | 切 |
| --- | --- | --- |
| 音声の加工 | 稲妻(`bolt.fill`) | 斜線つきの稲妻(`bolt.slash.fill`) |
| 消音 | 斜線つきのスピーカー(`speaker.slash.fill`) | 波つきのスピーカー(`speaker.wave.2.fill`) |
| ラウドネス | 波つきの耳(`ear.badge.waveform`) | 耳(`ear`) |
| イコライザー | 波形(`waveform`) | 斜線つきの波形(`waveform.slash`) |
  動き続けるもの(点滅など)は使わない。「視差効果を減らす」が入の Mac では動かさない。動きは見た目だけで、押してから効くまでの時間は変えない。

状況に応じて出す知らせ:

- いちばん上の帯に出すもの:
  - 音声の加工を切っている(オレンジ。アイコンの絵だけでなく、文でも伝える)。
  - 加工が止まっていて、元の音が最大音量で出ているおそれがある。加工を始められなかった(赤)。
  - 音を取り出せていない(「システム音声の録音」の許可がないおそれ)。「設定を開く」つき(8.1。赤)。
  - 設定やプリセットを、読めなかった・保存できなかった(オレンジ)。
  - 選んだ出力先へ、切り替えられなかった(オレンジ)。
- 音量の枠の中に出すもの: 音量キーに、アクセシビリティの許可が要る(「許可を求める…」つき)。または、キーを受け取れなかった。
- いちばん上の帯は、出るときは上から伸び、消えるときは上へ縮む(0.25 秒)。ほかの中身も、それに合わせてなめらかに動く(2026-10-20、利用者の指示)。
  帯の文や色が変わるとき(加工が止まっている → 切、など)は、同じ帯のまま中身を入れ替える(2枚を重ねて出さない)。
  「視差効果を減らす」が入の Mac では、動かさずに切り替える。

加工を切っているとき、加工が止まっているとき、音を取り出せていないときは、メニューバーのアイコンを警告の印に変える。
加工を始められなかったときも同じだが、音量調整が無効の出力先(macOS の音量が効く)では、危なくないので変えない。

```
+------------------------------------------+
| (加工)  [ USB SPDIF Adapter          v ] |
| +--------------------------------------+ |
| | (消音)  ==========O-------------  42 | |
| +--------------------------------------+ |
| +--------------------------------------+ |
| | (入切)  =======O----------------  40 | |
| | (入切) (開く)  [ 映画             v ] | |
| +--------------------------------------+ |
| (設定)                            (終了) |
+------------------------------------------+
```

確かめるカード(2026-11-07、利用者の指示):

ポップアップの操作で確かめるときは、別のダイアログではなく、ポップアップの中にカードを出す(画面の真ん中のダイアログでは、目線の移動が大きいため)。

- 出す場面は3つ。ほかの場面(イコライザーのウィンドウの操作、⌘Q、ほかのアプリからの終了の頼み、「音を取り出せていません」の案内)は、ダイアログのまま。

  | 場面 | 出す場所 | 見出し | 進めるボタン |
  | --- | --- | --- | --- |
  | 稲妻のボタンで、加工を切る | いちばん上 | 音声の加工を切りますか? | 切る |
  | ✕ のボタンで、加工中に終える | いちばん下 | SimpleEqualizer を終了しますか? | 終了 |
  | プリセットの選択パネルで、保存していない変更があるまま別のプリセットを選ぶ | いちばん上(選択パネルがカードに移り変わる) | 「〇〇」への変更を保存していません | 変更を捨てて切り替える |

- 押した場所の近くに出す(2026-11-07、利用者が選んだ)。ほかの中身は、選択パネルを開くときと同じように退く。ポップアップの大きさは変えない。
- カードには、見出し(太字)、説明(ダイアログと同じ文)、右寄せのボタン2つ(「キャンセル」、進めるボタン)を並べる。進めるボタンは赤い文字にする。
- キー: Esc でキャンセル。Return キーでは、どちらのボタンも押せない。Tab でボタンを移り、はじめは「キャンセル」にいる(キーボードで操作するとき)。
- カードを出している間は、ほかの操作(音量、選択パネル、ほかのボタン)はできない。音量キーは、いままでどおり効く。
- ポップアップを閉じたら(外を押した、メニューバーのアイコンを押した)、キャンセルとみなす。次に開いたときは、ふだんの画面に戻っている。
- 確かめる理由がなくなったら、何もせずにカードを閉じる(加工が自動で止まった、プリセットの変更がなくなった、など)。
- カードを出している間に ⌘Q を押したら、カードを閉じて、ダイアログで確かめる。
- ✕ のカードで「終了」を押したら、そのまま終える(ダイアログで二度確かめない)。キャンセルしたあとの ⌘Q では、ダイアログで確かめる。
- 読み上げ(VoiceOver)では、カードが出たら、カードに移る。
- 「視差効果を減らす」が入の Mac では、選択パネルと同じく、ぼかし・縮み・移動をせず、薄くなって入れ替わるだけにする。

```
稲妻のボタンを押したとき:
+------------------------------------------+
| +--------------------------------------+ |
| | 音声の加工を切りますか?              | |
| | 音は、加工なしの最大音量に戻ります。 | |
| | 先に、スピーカー側の音量を下げて     | |
| | ください。                           | |
| |              [キャンセル] [ 切る ]   | |
| +--------------------------------------+ |
|   (退いた中身)                           |
+------------------------------------------+
```

### 5.2 イコライザーのウィンドウ

- プリセットの選択と、イコライザーの入・切
- 10 本の縦のスライダーと、それぞれの値(dB)
- プリセットの操作: 1段目「保存」「別名で保存…」「変更を戻す」「フラットに戻す」、2段目「名前の変更…」「削除…」「書き出し…」「読み込み…」
- リミッターが音を抑えているときの説明
- 音量調整が無効の出力先のときだけ、「増幅した分だけ、全体を自動で下げる」の入・切と、いま下げている量

操作:

- スライダーは、つまみを引いた長さのぶんだけ動く。押した場所へ値を飛ばさない(押しただけで急に増幅されるのを防ぐ)。
- 矢印キー: 左右でバンドを選び、上下で 0.5 dB ずつ、Shift + 上下で 2 dB ずつ変える。端では止まる。
  選んでいるバンドは、色と枠で示す。開いた直後は、いちばん左(31 Hz)を選んでいる。

```
+--------------------------------------------------------------+
| プリセット: [映画 *        v]             イコライザー [ON ] |
|                                                              |
| +10    |    |    |    |    |    |    |    |    |    |        |
|        |    O    O    |    |    |    |    O    O    |        |
|  0     O    |    |    O    O    O    O    |    |    O   dB   |
|        |    |    |    |    |    |    |    |    |    |        |
| -10    |    |    |    |    |    |    |    |    |    |        |
|        31   62  125  250  500   1k   2k   4k   8k  16k  Hz   |
|                                                              |
| [保存] [別名で保存…] [変更を戻す] [フラットに戻す]           |
| [名前の変更…] [削除…] [書き出し…] [読み込み…]               |
+--------------------------------------------------------------+
```

### 5.3 設定のウィンドウ

| 区分 | 項目 |
| --- | --- |
| 出力先 | いまの出力先、アプリの音量調整が有効か(自動で決まるので、切り替えはない)、「増幅した分だけ、全体を自動で下げる」 |
| 音量キー | 「キーボードの音量キーで、アプリの音量を変える」、アクセシビリティの許可の状態と「許可を求める…」 |
| 起動 | 「ログイン時に起動する」。macOS の許可が要るときは、案内と「設定を開く」 |

## 6. 保存するデータ

保存先は `~/Library/Application Support/SimpleEqualizer/`。形式は JSON。
ログイン時に起動するかどうかは、macOS が覚えるので、書かない。

`state.json`(前回の状態):

```json
{
  "version": 1,
  "outputs": {
    "装置の UID": { "volume": 30, "muted": false }
  },
  "equalizerEnabled": true,
  "equalizerGainsDb": [0, 4.0, 3.0, 1.5, 0, 0, 1.0, 2.0, 2.5, 2.0],
  "loudnessAmount": 40,
  "loudnessEnabled": true,
  "selectedPresetId": "UUID",
  "autoLowerEnabled": true,
  "volumeKeysEnabled": true
}
```

| 項目 | 内容 | ない・読めないとき |
| --- | --- | --- |
| `outputs` | 出力先ごとの音量と消音。装置は UID(macOS が装置につける識別子)で見分ける | 音量は 30(初期値の 100 にはしない) |
| `equalizerEnabled` | イコライザーの入・切 | ないときは入。書いてあるのに読めないときは切 |
| `equalizerGainsDb` | いまの 10 バンドの値(31 Hz から順に。保存していない変更を含む) | 個数が 10 でない、範囲の外、読めない値が1つでもあれば、すべて 0 dB |
| `loudnessAmount` | ラウドネスの強さ(0〜100) | 0。`loudnessAmount` がない古い形で `loudnessEnabled` が入なら 50 |
| `loudnessEnabled` | ラウドネスの入・切 | ないときは入。書いてあるのに読めないときは切。`loudnessAmount` がない古い形では入(強さに読み替える) |
| `selectedPresetId` | 選んでいるプリセットの `id` | 「フラット」 |
| `autoLowerEnabled` | 増幅した分だけ、全体を自動で下げるか | 入 |
| `volumeKeysEnabled` | 音量キーで、アプリの音量を変えるか | 入 |

`presets.json`(プリセットの一覧。書き出しのファイルも同じ形):

```json
{
  "version": 1,
  "presets": [
    { "id": "UUID", "name": "映画", "gainsDb": [0, 4.0, 3.0, 1.5, 0, 0, 1.0, 2.0, 2.5, 2.0] }
  ]
}
```

「フラット」は書かない(アプリが、いつも一覧の先頭に足す)。値が範囲の外のプリセットは、丸めずに読まない。

読めないファイルの扱い(2つのファイルに共通):

| 場合 | 動き |
| --- | --- |
| 全体が壊れている(`presets.json` にプリセットの一覧がない場合を含む) | 別名(`state.broken-<日時>.json` など)で残し、初期状態で始める |
| 新しい版のアプリが作った、版の番号が整数として読めない、あるのに読めない | 触らない。初期状態で始め、上書きしない |
| `presets.json` の一部のプリセットだけが壊れている | そのプリセットは読まない。元の写しを `presets.partial-<日時>.json` で残し、読めた分で書き直す |

## 7. 技術構成

| 項目 | 採用するもの |
| --- | --- |
| 言語・画面 | Swift、SwiftUI(`MenuBarExtra`)。Apple 標準のフレームワークだけを使う |
| 音声の取り出し | Core Audio のプロセスタップ(元の音を消す設定)と、アプリだけが使う集約装置 |
| 音声の加工 | `AVAudioEngine` の手動レンダリング(リアルタイム)。イコライザーは `AVAudioUnitEQ`(10 バンド)、ラウドネスは別の `AVAudioUnitEQ`(低域・高域のシェルフ型2つ) |
| 音声のコールバック | C で書く(Apple が、Swift を音声のリアルタイムのスレッドで使うことに対応していないため)。音量とリミッターも C。エンジンとつなぐところだけ Objective-C |
| 音量キー | `CGEventTap` でキー入力を受け取り、macOS に渡さない |
| ログイン時の起動 | `SMAppService` |
| 配布 | GitHub で公開している(7.1)。配布物は自己署名の証明書で署名する。サンドボックスは使わない |

処理の流れ:

```
各アプリの音 → タップ(元の音は消す) → イコライザー → ラウドネス → 音量 → リミッター → 出力先
```

- 自分自身の出力は、タップの対象から外す(外さないと音が循環する)。
- 取り出せるのは通常の音声(PCM)だけ。Dolby Digital などの圧縮された信号をそのまま通す再生は、加工できない。

## 8. 必要な許可

| 許可 | 用途 | 拒否された場合 |
| --- | --- | --- |
| システム音声の録音 | 音声の取り出し | 音を取り出せない(アプリは音量を変えられない)。案内を出し、設定を開けるようにする |
| アクセシビリティ | 音量キーの受け取り | 音量キーだけ使えない。メニューバーからの操作は使える |

### 8.1 「システム音声の録音」の許可がないときの案内

- 許可がなくても、経路は動き、取り出した音が無音になる。macOS には、この許可の状態をアプリから調べる方法がない。
- そこで、状況から判断する。次の状態が 10 秒ほど続いたら、音を取り出せていないと判断する。
  - ほかのアプリが、いまの出力先へ音を出している。
  - アプリは、加工を始めてから、無音でない音を一度も受け取っていない。
- 判断したら、案内の画面を出し(起動してから1回だけ)、メニューバーのアイコンを警告の印に変え、ポップアップに説明と「設定を開く」を出す。
  音を受け取れるようになったら消す。
- 限界: ほかのアプリが無音のまま出力を動かしている場合(一時停止中の動画など)は、まちがって案内が出ることがある。
- 許可を出したあとは、アプリを起動し直す。

## 9. 性能

| 項目 | 目標 | 実測(Debug ビルド) |
| --- | --- | --- |
| CPU 使用率 | 再生中で 3% 以下 | 3% 未満(経路2本、静かに再生している間 2.5〜3.0%。画面を操作している間は 8% ほど) |
| 音の遅れ | 50 ミリ秒以下 | 装置の申告とバッファの合計で 15.8 ミリ秒(再生するアプリ側とスピーカー側の遅れは含まない) |
| 音切れ・雑音 | スライダー操作中、抜き差し、スリープからの復帰を含めて出さない | 出ていない(利用者が確かめた) |
| メモリ | 連続稼働しても増え続けない | 半日の使用で、増え続けなかった |

最適化ありのビルド(Release)でも、CPU 使用率は 3% 未満だった(2026-10-18、利用者が確かめた)。

## 10. 対象外

- アプリごとの音量調整
- 複数の出力先を同時に加工すること(内部では経路を複数持つが、音が出るのはいまの出力先だけ)
- SONOS のネットワーク操作(案C)。次の段階の候補(継続の課題)
- 周波数の波形表示(スペクトラム)
- App Store での配布
