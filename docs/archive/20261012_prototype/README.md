# 試作の音声のコード(2026-10-12)

試作(`../tickets/20261012_prototype/`)で使った、Swift だけで書いた音声のコード。
段階2 の TICKET-003 で、音声のスレッドで動く部分を C に書き直したときに、アプリから外してここへ移した。
ビルドの対象ではない。参考として残している。

| ファイル | 内容 |
| --- | --- |
| `AudioPassthrough.swift` | タップと集約装置を作り、コールバックで音量を掛ける。`AVAudioEngine` を通す経路(`renderThroughEngine`)も入っている |
| `EngineProcessor.swift` | `AVAudioEngine` を手動レンダリングで動かす部品(1 kHz の1バンド) |

段階3(イコライザー)で `AVAudioEngine` の経路を作り直すときは、次の点を引き継ぐ。

- エンジンは「手動レンダリング(リアルタイム)」にし、ほかの部品に触る前に切り替える。
- エンジンの中は、チャンネル別の標準の形式にそろえる。左右交互の音との並べ替えは自分で行い、置き場は開始のときに確保する。
- ノードをつなぐときは、失敗時にエラーを返す関数(`connectNode`)を使う。
- エンジンを通せなかった回は、無音にせず、加工なしの音に切り替える。
- 調べた内容は `../../research/AVAudioEngine_Tap.md` にある。
