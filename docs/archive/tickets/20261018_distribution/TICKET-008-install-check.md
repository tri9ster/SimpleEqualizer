## 対応方針・作業手順

1. 手順を書いて、利用者の確認を受けてから進める:
   - 古いアプリの登録を外す(同じ識別子のアプリが2つ登録されないようにする。`failures.md` の、仮のアイコンの件)。
   - 配布物から `/Applications` に置く。ログイン時の起動を登録し直す。許可を出し直す必要があれば出す。
   - アクセシビリティの許可を求めたときに、一覧にアプリが出るかを確かめる(TICKET-006 の試験では出ず、「+」で足した)。
   - 識別子を変える前のアプリの、残りを片付ける: ログイン項目(システム設定の「ログイン項目」)、許可の一覧の古い行、
     macOS の登録(`lsregister`)。試験用フォルダ(デスクトップの `SimpleEqualizer-test`)も消す。
2. 利用者に、段階5 の TICKET-008 と同じ確認を頼む(起動と終了、音量キー、出力先の切り替え、スリープ、ログイン時の起動、負荷)。
   **スピーカー側の音量を下げてから試す。**
