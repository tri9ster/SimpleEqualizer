# TICKET-007: README(英語と日本語)

## 概要

GitHub で読む README を、英語と日本語で用意する。開くときの警告と開き方、許可の出し方、ソースからのビルドの方法を書く。

## 現状

2026-10-18 時点。未着手。

- `README.md` は日本語の1本で、自分で使う前提の書き方になっている。
- 画面と README には、特定の機材の名前を書かない(`CLAUDE.md`)。

## 対応方針・作業手順

1. 分け方を決める(案: `README.md` を英語、`README.ja.md` を日本語にし、互いに案内を置く)。
2. 書くこと:
   - 何をするアプリか、動く環境(macOS 27 以降、Apple シリコン)。
   - 入れ方。**開くときに macOS の警告が出ること、その理由(Apple の公証を受けていない)、開き方。**
   - 許可(システム音声の録音、アクセシビリティ)と、なぜ要るか。
   - 音を出すときの注意(アプリを止めると、元の音量で音が出ること。スピーカー側の音量を下げてから試すこと)。
   - 使い方、ソースからのビルドの方法(自分の `Config/Signing.xcconfig` を作る)、利用許諾(MIT)。
3. 利用者に確かめてもらう。
