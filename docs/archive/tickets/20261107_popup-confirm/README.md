# ポップアップの中の確かめる画面 チケット一覧(2026-11-07)

ポップアップの操作から出る確かめる画面を、別のダイアログではなく、ポップアップの中に出す(利用者の指示)。
ポップアップはふだんの操作の場所で、画面の真ん中にダイアログが出ると、目線の移動が大きいため。
出力先とプリセットの選択パネル(2026-10-20)と同じように、ポップアップの中で開いて閉じる。

対象は、ポップアップの操作から出る3つだけ(2026-11-07、利用者が決めた)。

| 確かめる画面 | ポップアップでの操作 | ポップアップの外から出るとき |
| --- | --- | --- |
| 音声の加工を切りますか? | 稲妻のボタン | なし |
| SimpleEqualizer を終了しますか? | ✕ のボタン | ⌘Q、ほかのアプリからの終了の頼み。いまのダイアログのまま |
| 「〇〇」への変更を保存していません | プリセットの選択パネルで、別のプリセットを選ぶ | イコライザーのウィンドウ。いまのダイアログのまま |

イコライザーのウィンドウの確かめる画面、名前を入れる画面、ファイルを選ぶ画面、知らせ、「音を取り出せていません」の案内は、変えない。

## 作業順序

```
TICKET-001 見た目と動きを決める(仕様書)
    └─ TICKET-002 確かめる画面の部品と、音声の加工を切るとき
           ├─ TICKET-003 ✕ のボタンで終了するとき
           └─ TICKET-004 プリセットを切り替えるとき
```

- 001 を先にする理由: 見た目と動き(どこに出すか、キーの扱い、閉じたときの扱い)を、作る前に決めて確かめてもらう。
- 002 で部品を作り、いちばん簡単な場面(加工を切る)で、動きを確かめてもらう。003、004 は、その部品を使う。
- 003 は、終了の入口(⌘Q と同じ道)との二重の確かめを避ける作りが要るので、別にする。
