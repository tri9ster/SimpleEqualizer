# TICKET-001: 見た目と動きを決める(仕様書)

## 概要

ポップアップの中に出す確かめる画面の、見た目、動き、キーの扱い、閉じたときの扱いを決めて、仕様書に書く。
作る前に、利用者に確かめてもらう。

## 現状

2026-11-07 時点。

- 確かめる画面は、すべて `Dialogs.confirm`(`NSAlert`)で、画面の真ん中に、別のウィンドウとして出る。
  進めるボタンは、Return キーでは押せず、Esc でキャンセルできる(仕様書 5章)。
- ポップアップには、選択パネル(出力先、プリセット)がある。開くと、ほかの中身が退き、押したタイルがパネルへ広がる(仕様書 5.1)。

## 対応方針・作業手順

1. 次を決めて、図(文字で描く)と一緒に利用者に見せる。Claude の案:
   - 出し方: 選択パネルと同じく、ほかの中身が退き、その上に確かめる画面のカードが出る。ポップアップの大きさは変えない。
     カードには、見出し(「音声の加工を切りますか?」)、説明(「音は、加工なしの最大音量に戻ります。…」)、ボタン2つ(キャンセル、進める)。
   - 進めるボタン(「切る」「終了」「変更を捨てて切り替える」)は、赤い文字にする。Return キーでは押せない。Esc でキャンセル。
     ほかのダイアログと同じ決まり。
   - 確かめる画面を出している間は、ほかの操作(音量、選択パネル)をできなくする。
   - ポップアップを閉じたとき(外を押した、メニューバーのアイコンを押した)は、キャンセルとみなす。次に開いたときは、ふだんの画面に戻っている。
   - 「視差効果を減らす」が入の Mac では、選択パネルと同じく、薄くなって入れ替わるだけにする。
   - 読み上げ(VoiceOver)では、確かめる画面に移る。
2. 利用者の確認を受けてから、仕様書の 4.4(プリセット)、4.7(常駐と起動)、5章、5.1 と、変更履歴を直す。

## 実施結果

2026-11-07 に仕様書(4.4、4.7、5章、5.1 の「確かめるカード」、12章)に書き、利用者が確かめた。

- カードを出す場所は、利用者が選んだ: 押した場所の近く(加工を切る → いちばん上、終了 → いちばん下、プリセット → 選択パネルがそのままカードに移り変わる)。
  ほかの案は、「いつもいちばん上」「いつも真ん中」。
- Claude の案のまま書き、利用者が認めたこと: ボタンの並びと色、キー(Esc、Return、Tab)、出している間はほかの操作をできなくする、
  閉じたらキャンセル、理由がなくなったら閉じる、出している間の ⌘Q、✕ のカードのあとで二度確かめない、読み上げ、「視差効果を減らす」。
- TICKET-003、004 の「決めること」(⌘Q との重なり、プリセットの変更がなくなったとき)も、ここで決めた。
