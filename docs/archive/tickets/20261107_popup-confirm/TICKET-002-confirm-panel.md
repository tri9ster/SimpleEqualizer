# TICKET-002: 確かめる画面の部品と、音声の加工を切るとき

## 概要

ポップアップの中に出す確かめる画面の部品を作り、稲妻のボタンで音声の加工を切るときに使う。

- [x] 完了

## 依存関係

TICKET-001

## 現状

2026-11-07 時点。

- 稲妻のボタンは `PopupView.toggleProcessing` で、`Dialogs.confirmLoudSound` を呼び、ダイアログを閉じるまで待つ。
- 選択パネルは、`PopupView` の `expanded` と `isReceded`(ほかの中身を退かせる)で開閉している。

## 対応方針・作業手順

1. `PopupView` に、出している確かめる画面(なし、加工を切る、…)の状態を持たせる。選択パネルと同時には開かない。
   ほかの中身を退かせるしくみ(`receding`)は、選択パネルと同じものを使う。
2. 確かめる画面のカード(見出し、説明、キャンセル、進める)を作る。進めるボタンは Return キーで押せないようにし、Esc でキャンセルにする。
3. ポップアップが閉じたら、確かめる画面も閉じる(キャンセル)。閉じたことの受け取り方を調べる(`MenuBarExtra` の `.window` の形)。
4. 稲妻のボタンを、この部品に切り替える。進めたら `model.stopProcessing()`。
5. 新しい文言は、日本語と英語の両方を用意する(`tools/sync-strings.sh`)。いまのダイアログの文言を使い回せるものは使う。
6. 仕様書、`README.md` と `README.ja.md`(確かめる画面の説明があれば)、`architecture.md`、`dev-log.md` を直す。
7. 利用者に確かめてもらう。**スピーカー側の音量を下げてから試す**(加工を切ると、最大音量に戻るため)。

## 実施結果

2026-11-07 に作り、利用者が確かめた(動作確認項目のすべて)。

- `PopupView` に、出している確かめるカード(`Confirmation`)を持たせた。いまは「加工を切る」だけ。出す場所は `Confirmation.edge`。
- カード(`ConfirmCard`)は、見出し、説明、「キャンセル」(Esc)、進めるボタン(赤い文字。既定のボタンにしないので、Return キーでは押せない)。
  はじめは「キャンセル」にいる。読み上げは見出しに移り、カードの外へは移れない(`isModal`)。
- 出すときは、選択パネルと同じく、ほかの中身を退かせてから、上端を軸に少し縮んだところから広げる。
- ポップアップを閉じたら閉じる(キャンセル)。加工が自動で止まったら、何もせずに閉じる。
- 説明の文は、ダイアログと同じもの(`Dialogs.loudSoundDetail`)を使う。新しい文言はない(カタログは変わらない)。
- README(英語と日本語)の、稲妻のボタンの説明を直した。
- `/code-review` の指摘で、利用者が確かめたあとに直したこと:
  - 重ねる場所を、上と下で分けた(1つだと、閉じた瞬間に場所が決まらず、いちばん下のカードの消える動きが上端へ飛ぶ。TICKET-003 で効く)。
  - はじめに「キャンセル」へ移すのを、次の更新まで待つようにした(出てくる動きの途中では、移れないことがある)。
  - パネルとカードの動きの指定と背景を、1か所にまとめた(`appearAnimation`、`disappearAnimation`、`popupPanelBackground`)。
- 指摘のうち、あとのチケットで直すもの:
  - カードを出している間に ⌘Q を押すと、カードが残ったまま、ダイアログが出る(TICKET-003)。
  - 退かせる状態(`isReceded`)を、パネルとカードで分け合っている。片方を閉じると、もう片方を出していても中身が戻る(TICKET-004。パネルからカードへ移るとき)。
- 未確認: 直したあとの、キーボードで操作するときのはじめの位置(Tab の移り方)。
