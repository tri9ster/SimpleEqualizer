# TICKET-004: プリセットを切り替えるとき

## 概要

ポップアップのプリセットの選択パネルで、保存していない変更があるまま別のプリセットを選んだときの確かめる画面を、ポップアップの中に出す。
イコライザーのウィンドウで選んだときは、いまのダイアログのまま残す(2026-11-07、利用者が決めた)。

## 現状

2026-11-07 時点。

- 選択パネルで選ぶと、パネルを閉じてから `PresetActions.select` を呼ぶ。保存していない変更があると、`Dialogs.confirmDiscardingChanges` でダイアログを出す。
  イコライザーのウィンドウのプルダウンも、同じ `PresetActions.select` を使う。
- 説明の文(`discardDetail`)は、いまの状態に合わせて、できる操作だけを案内する(イコライザーのウィンドウで「別名で保存」、など)。

## 対応方針・作業手順

1. ポップアップから選んだときは、変更があれば、ポップアップの中に確かめる画面を出す。進めたら `model.selectPreset(id)`。
   イコライザーのウィンドウから選んだときは、いまのまま。
2. 選択パネルを閉じる動きと、確かめる画面を出す動きが、続けて自然に見えるようにする(パネルを閉じてから出すか、パネルから直接移るかは、001 で決める)。
3. 確かめる画面を出している間に、イコライザーのウィンドウで値や選択が変わったときの扱いを決める(案: 変更がなくなったら、確かめずに閉じる)。
4. 説明の文は、いまと同じもの(`discardDetail`)を使う。
   退かせる状態(`isReceded`)は、パネルとカードで分け合っている。パネルからカードへ移るときに、中身が戻らないよう、
   パネルとカードの両方を見て決める形にする(TICKET-002 の見直しで出た)。
5. 仕様書(4.4、5.1)、`dev-log.md` を直す。
6. 利用者に確かめてもらう(音が大きくなる設定に切り替わることがあるので、スピーカー側の音量を下げてから試す)。

## 実施結果

2026-11-07 に作り、利用者が確かめた(動作確認項目のすべてと、カードを出したままイコライザーのウィンドウで保存すると閉じること。稲妻と ✕ のカードも、いままでどおり)。

- 選択パネルで、保存していない変更があるまま別のプリセットを選ぶと、パネルが消えて、同じ場所(いちばん上)に確かめるカードが出る。
  中身は退いたまま(`switchPanel`)。変更がないときは、いままでどおり、パネルを閉じてから切り替える。
- カードは、そのとき選んでいたプリセットと、切り替える先を覚える(`Confirmation.discardChanges`)。
  変更がなくなった、選んでいるプリセットが変わった、切り替える先が消えたときは、何もせずに閉じる(`closeConfirmationIfUnneeded`)。
- 見出し、説明、ボタンの文言は、イコライザーのウィンドウのダイアログと同じもの(`Dialogs.discardChangesMessage`、`PresetActions.discardDetail`)。新しい文言はない。
- 退かせる状態(`isReceded`)は、パネルを閉じるときはカードを、カードを閉じるときはパネルを見て決めるようにした(TICKET-002 の見直しで出た)。
- `/code-review` の指摘で、利用者が確かめたあとに直したこと:
  - パネルからカードに切り替わる途中は、パネルの見出しの Esc を止め、Esc がカードの「キャンセル」に届くようにした(途中で押すと、Esc が空振りすることがあった)。
  - 「変更を捨てて切り替える」を押した瞬間にも、確かめる理由があるかを見直し、なければ切り替えない(`isNeeded`)。
  - 変更がないときは、`PresetActions.select` を通さず、直に切り替える(ダイアログが出ない道だと分かるように)。
- 指摘のうち、直さなかったこと:
  - パネルが消えるとき、プリセットの欄の位置へ縮みながら消え、同時にカードがいちばん上に出る。利用者が見て、不自然ではないとした。
  - カードの見出しの名前は、いま選んでいるプリセットから引く。選択が変わると、閉じる前の一瞬だけ、新しい名前になりうる(すぐ閉じる)。
- 未確認: 直したあとの動き(切り替わる途中の Esc)。
