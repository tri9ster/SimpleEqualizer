# 終了するときの確かめの条件 チケット一覧(2026-11-07)

終了するときに確かめる条件を見直す。

- 発端: 利用者が、確かめずに終わる場面を見つけた(2026-11-07)。様子を聞くと、稲妻のボタンで加工を切ったあとに、
  ✕ や ⌘Q で終えた場面だった。加工を切った時点で音は元に戻っていて、終えても変わらないので、仕様どおり(仕様書 4.7)。
  仕様は変えない(2026-11-08、利用者が決めた)。
- 残る心配: 稲妻が「入」のまま、いまの出力先の加工だけが止まっている間は、ほかの出力先の経路が元の音を消していても、
  確かめずに終わるかもしれない(コードを読んで考えたこと。まだ確かめていない)。これを確かめ、本当なら直す。

## 取りやめ(2026-11-08)

利用者が、このチケットを取りやめた。どれも着手していない。残る心配と言い過ぎの件は、`docs/TODO.md` の「終了の確かめ」に残す。

## 作業順序

```
TICKET-001 再現と原因の特定
    └─ TICKET-002 確かめる条件を直す(✕、⌘Q、稲妻のボタン)
           └─ TICKET-003 macOS の音量で変える出力先では、言い過ぎない(任意)
```

- 001 を先にする理由: 推測で直さない。確かめずに終わる場面が本当にあるのか、先に確かめる。なければ 002 は行わない。
- 002 は、001 で分かった原因にもとづいて直す。直し方は、001 の結果を見て、利用者と決める。
- 003 は、確かめが「出すぎる」側の話で、危なくはない。002 と同じ条件の話なので、続けて行うか、002 にまとめるかを、001 のあとに決める。
