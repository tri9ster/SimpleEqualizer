# TICKET-003: macOS の音量で変える出力先では、言い過ぎない(任意)

## 概要

内蔵スピーカーのように、macOS の音量で変える出力先でも、加工中なら「音は、加工なしの最大音量に戻ります」と確かめる。
実際の音量は macOS の音量のままなので、言い過ぎになる。不要な確かめが多いと、確かめが読まれなくなる。
危なくはないので、任意とする。TICKET-002 と同じ条件の話なので、まとめて行うかを、TICKET-001 のあとに決める。
