# TICKET-005: ラウドネス

## 概要

小さい音量で聞こえにくくなる低音と高音を、音量に応じて自動で持ち上げる機能を入れる(仕様書 4.3)。
補正量は仮の値で作り、利用者が聴いて決める。

## 対応方針・作業手順

### 動き

- ポップアップに「ラウドネス」の入・切を足す。初期値は切。状態は保存する。
- 入のとき: 音量が変わるたびに、補正量を計算し直して、フィルターに設定する。
  - 音量 100 で補正なし。音量を下げるほど補正が増える。
  - 消音中は、補正量を変えない(消音を解いたときに、そのままの音で戻る)。
- 切のとき: 補正量を 0 dB にする。
- イコライザーを切にしても、ラウドネスは効いたままにする。

### 聴いて決めること

仮の値で作ったあと、利用者に聴いてもらい、次を決める。変えるときは、テストを先に直す。

| 項目 | 仮の値 |
| --- | --- |
| 低音の補正の上限 | +8 dB |
| 高音の補正の上限 | +3 dB |
| 上限に達する音量 | 22(音量による減衰が 40 dB) |
| 低音を持ち上げる範囲 | 100 Hz より下 |
| 高音を持ち上げる範囲 | 8 kHz より上 |

- スピーカー本体にもラウドネスの設定がある場合は、二重に掛かる。アプリ側を使うときは、スピーカー側を切ってもらう
  (SONOS Ray にはこの設定がある。仕様書 4.3)。確認の前に伝える。

### 安全のための決まり

- 補正は、いつも音量による減衰より小さくする(ラウドネスだけで、元の音量を超えない)。
  聴いて式を変えるときも、この条件を保つ。テストで確かめる。
- 段階3 のあいだ、対象は USB SPDIF Adapter だけで、音量調整はいつも有効。
  「音量調整が無効のときはラウドネスを使えない」(仕様書 4.3)は、段階5 で作る。

## 実施結果

2026-10-12 に実装した。利用者に3回聴いてもらい、入・切を強さのスライダーに変え、補正量を直した(下の経過)。
4回目の値(上限を 1.5 倍にしたもの)で、利用者が確かめた(2026-10-12、`input/memo.md`):
足りるようになった。音量 100 では、強さを変えても音が変わらない。起動し直すと、強さが元に戻る。
補正量は、この値(強さ 100 で低音 +15 dB、高音 +6 dB、音量 50 あたりで上限)に決まった。

### 作ったもの

- ポップアップに「ラウドネス」を足した。はじめは入・切のスイッチで作り、利用者の要望で、強さのスライダーに変えた(下の経過)。
- 音量や強さが変わるたびに補正量を計算し直し、変わったときだけエンジンへ伝える。
- 起動時と、加工を入れ直したときは、音を出し始める前に、その出力先の音量から決めた補正量をエンジンへ渡す。
- 補正量は、音に掛けるのと同じ音量から決める(`OutputSettings.loudness(amount:)`)。消音の切り替えでは変わらない。
- 強さのスライダーは、音量と同じく、加工していない間は動かせない。

### 聴いて決める(経過)

1回目(2026-10-12): 利用者の感想は「小さい音量で効きすぎる。中くらいの音量で、もっと効いてほしい」。
入・切や音量を動かしたときの雑音についての指摘はなかった(個別の結果は聞いていない)。

2回目の値(2026-10-12): 上限を下げ、上限に達する音量を上げた。テストを先に直してから、値を変えた。

| 項目 | 1回目 | 2回目 |
| --- | --- | --- |
| 低音の補正の上限 | +8 dB | +5 dB |
| 高音の補正の上限 | +3 dB | +2 dB |
| 上限に達する音量 | 22(減衰 40 dB) | 50(減衰 18 dB) |

| 音量 | 1回目(低音 / 高音) | 2回目(低音 / 高音) |
| --- | --- | --- |
| 90 | +0.5 / +0.2 dB | +0.8 / +0.3 dB |
| 70 | +1.9 / +0.7 dB | +2.6 / +1.0 dB |
| 60 | +2.7 / +1.0 dB | +3.7 / +1.5 dB |
| 50 | +3.6 / +1.4 dB | +5.0 / +2.0 dB |
| 30 | +6.3 / +2.4 dB | +5.0 / +2.0 dB |
| 20 以下 | +8.0 / +3.0 dB | +5.0 / +2.0 dB |

利用者が「小さい音量」「中くらいの音量」と感じる数値は、聞いていない。

2回目の感想(2026-10-12): 「中くらいのときの効き具合が弱い」。
あわせて、要望があった: **ラウドネスを、入・切ではなく、効き具合をスライダーで変えられるようにする。**

3回目(2026-10-12): 入・切のスイッチをやめ、強さ(0〜100)のスライダーにした。仕様の変更なので、仕様書 4.3 を書き直した(版 0.17)。

- 補正量は、強さに比例する。強さ 0 で切。初期値は 0。
- 音量に対する形は、2回目と同じ(音量 50 あたりで上限に達し、それより下げても増えない)。
- 強さ 100 での上限は、低音 +10 dB、高音 +4 dB。強さ 50 が、2回目の値と同じになる。
  「中くらいで弱い」に応えられるよう、2回目の倍まで上げられるようにした。
- 補正は、強さ 100 でも、いつも音量による減衰より小さい(テストで確かめている)。
- 保存する項目を、`loudnessEnabled`(入・切)から `loudnessAmount`(強さ)に変えた。
  入・切で保存してあったファイルは、入なら強さ 50 として読む。読めない強さ、範囲の外の強さは 0 にする。

| 音量 | 強さ 50(2回目と同じ) | 強さ 100 |
| --- | --- | --- |
| 90 | +0.8 / +0.3 dB | +1.5 / +0.6 dB |
| 70 | +2.6 / +1.0 dB | +5.2 / +2.1 dB |
| 60 | +3.7 / +1.5 dB | +7.4 / +3.0 dB |
| 50 以下 | +5.0 / +2.0 dB | +10.0 / +4.0 dB |

3回目の感想(2026-10-12): 上限を上げてほしい。スライダーを動かしている間の雑音はない。刻み(5 ずつ)はちょうどよい。

4回目(2026-10-12): 強さ 100 での上限を 1.5 倍にした(低音 +10 → +15 dB、高音 +4 → +6 dB)。テストを先に直してから、値を変えた。

- 同じ強さの数字でも、効き方が 1.5 倍になる。前に選んだ強さのまま起動すると、前より強く効く。
  3回目と同じ効き方にするには、強さを 3 分の 2 にする(100 → 65 あたり)。
- 上限は、これ以上は 18 dB までしか上げられない(それを超えると、ラウドネスだけで元の音量を超える)。
- 補正量を一度に書き換えることによる雑音は、利用者が聴いて、なかった(`/code-review` の指摘は解消)。

| 音量 | 強さ 50 | 強さ 100 |
| --- | --- | --- |
| 90 | +1.1 / +0.5 dB | +2.3 / +0.9 dB |
| 70 | +3.9 / +1.5 dB | +7.7 / +3.1 dB |
| 60 | +5.5 / +2.2 dB | +11.1 / +4.4 dB |
| 50 以下 | +7.5 / +3.0 dB | +15.0 / +6.0 dB |
