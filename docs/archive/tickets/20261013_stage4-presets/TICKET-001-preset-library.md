## 対応方針・作業手順

### プリセット(`Preset`)

- 項目: `id`(UUID)、`name`(名前)、`gains`(`EqualizerSettings`)。
- 「フラット」は、決まった `id` を持つ、はじめからあるプリセット。値はすべて 0 dB。

### 一覧(`PresetLibrary`)

- 並び順: 先頭が「フラット」。そのあとは、作った順。
- 操作(どれも、結果が成功か、できない理由かを返す):
  - 足す(「別名で保存」): 名前と値から、新しいプリセットを作る。
  - 上書き(「保存」): その `id` のプリセットの値を、いまの値にする。
  - 名前の変更。
  - 削除。
- できないこと:
  - 「フラット」の上書き、名前の変更、削除。
  - 空の名前、30 文字を超える名前。名前は、前後の空白を取ってから調べる。
  - ほかのプリセットと同じ名前(一覧の README の「2」)。「フラット」という名前も、ほかのプリセットには使えない。
  - 一覧にない `id` への操作。
- 調べること:
  - `id` からプリセットを探す。
  - いまの値が、選んでいるプリセットの値と違うか(変更の印 `*` に使う)。一覧にないプリセットは、「フラット」と比べる。
  - 読み込みのために、名前が重なるときの新しい名前(「映画 2」「映画 3」)を作る。
- プリセットの数の上限は、置かない。

### 着手後に決めたこと(名前の整え方)

見分けのつかない別名を作らせないために、名前を次のように整えてから、調べて保存する。

- 続いた空白、改行、タブは、空白1つにまとめる。前後の空白は取る。
- 見えない文字(幅のない空白など)と、制御文字は取り除く。絵文字をつなぐ文字は残す。
- 長さは 30 文字まで。あわせて、中身の長さにも上限を置く(見た目は1文字でも、記号を何百個も重ねた名前を防ぐ)。
- 名前が重なるときにつける番号は、重ねない(「映画 2」から作るのは「映画 3」。「映画 2 2」にしない)。
