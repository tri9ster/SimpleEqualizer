## 対応方針・作業手順

- 「名前の変更」: 名前を入れる画面を、いまの名前を入れた状態で出す。使えない名前のときは、理由を出して、入れ直してもらう。
- 「削除」: 確かめる画面を出してから消す(元に戻せないため)。消したあとは、「フラット」を選んだ状態にする。
  - スライダーの値は、「フラット」の値(すべて 0 dB)にする。音が変わるので、確かめる画面に、そのことを書く。
- 「フラット」を選んでいるときは、どちらも押せない。
- 一覧を変えたら、すぐ `presets.json` に保存する。

### 作ったもの

- イコライザーのウィンドウに、「名前の変更…」「削除…」を足した(ボタンの2段目)。「フラット」を選んでいるときは押せない。
- 名前を入れる画面は、「別名で保存」と共用にした。使えない名前のときは、理由を出して、入れ直してもらう。

### チケットから変えたこと

- **削除のあとの動きは、いったん変えたが、チケットのとおりに戻した。**
  - Claude は、`/code-review` の指摘を受けて、「削除しても、スライダーの値と音を変えない(『フラット *』になる)」形にした。
    音を下げる設定のプリセットを消すと、その瞬間に音が大きくなるためである。
  - 利用者の判断(2026-10-13): 削除したあとは、フラットに戻る動きにしたい。消したあとに `*` が出るのは、状況が分かりにくい。
  - そこで、チケットのとおり、消したあとは「フラット」に切り替え、値もすべて 0 dB にする。
    音が大きくなりうることは、確かめる画面に書いた(「音を下げる設定だったときは、音が大きくなります」)。
- **確かめる画面の「進める」ボタンを、Return キーでは押せないようにした。** 押したはずみで、元に戻せない操作が進まないようにする。
  Esc でキャンセルできる。プリセットの画面だけでなく、段階2 で作った「終了」「音声の加工を切る」の画面も同じにした
  (どちらも、音が最大音量に戻る操作である)。
- **すべて 0 dB の値でプリセットを上書きするときは、確かめる。** 「フラットに戻す」は値だけを 0 dB にして、選んでいるプリセットは変えない。
  「フラット」を選んだつもりで隣の「保存」を押すと、作った設定が 0 dB で上書きされ、元に戻せない。
- 削除と「別名で保存」のあとは、プリセットの一覧だけでなく、状態(選んでいるプリセット)も、待たずにすぐ保存する。
