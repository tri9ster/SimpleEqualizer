# TICKET-005: 書き出しと読み込み

## 概要

プリセットを1つのファイルに書き出し、読み込めるようにする(バックアップ用。仕様書 4.4)。

## 対応方針・作業手順

- イコライザーのウィンドウに、「書き出し」「読み込み」を足す。
- 「書き出し」: 保存先を選ぶ画面(macOS の標準)を出し、全部のプリセット(「フラット」を除く)を1つのファイルに書く。
  プリセットが「フラット」しかないときは、押せない。
- 「読み込み」: ファイルを選ぶ画面を出し、いまの一覧に足す(一覧の README の「4」。利用者の判断による)。
  - 終わったら、読み込んだ数と、読まなかった数(壊れていたもの)を出す。
  - 読めないファイル、新しい版のファイルのときは、何も足さずに、理由を出す。
  - 読み込んだだけでは、音は変わらない(選んでいるプリセットは変えない)。
- 保存先とファイルを選ぶ画面は、利用者が選んだ場所だけを読み書きする。プロジェクトのフォルダには書かない。

### 作ったもの

- イコライザーのウィンドウの2段目の右に、「書き出し…」「読み込み…」を足した。
- 「書き出し…」: 保存先を選ぶ画面(macOS の標準)を出し、全部のプリセット(「フラット」を除く)を1つのファイルに書く。
  はじめに入っている名前は「SimpleEqualizer プリセット.json」。プリセットが「フラット」だけのときは押せない。
- 「読み込み…」: ファイルを選ぶ画面を出し、いまの一覧に足す。終わったら、読み込んだ数と、読み込まなかった数を出す。
  読み込んだだけでは、選んでいるプリセットとスライダーの値は変わらない。
- 選べるのは、`.json` のファイルだけ。

### 着手後に決めたこと

- **保存していない変更があるまま書き出すときは、確かめる。** 書き出されるのは保存してある値で、いまのスライダーの値ではない。
  知らないまま、古い値をバックアップしないようにする。
- **読み込めるのは、1つのファイルにつき 500 件まで、大きさは 2 MB まで。** まちがったファイルを選んだときに、
  画面が長く固まったり、一覧があふれたりしないようにする。超えるときは、何も足さずに、理由を出す。

### `/code-review` の指摘と対処

| 指摘 | 対処 |
| --- | --- |
| 読み込むファイルの大きさと件数に上限がなく、画面が固まったり、一覧があふれたりする | 上限を置いた(500 件、2 MB)。テストを足した |
| 保存先やファイルを選ぶ画面が、ほかのウィンドウの裏に出るおそれ | 確かめる画面と同じく、前面に出す |
| ファイルに書けなかったときも、先に「読み込みました」と出る | 1つの画面で、読み込めたことと、書けなかったことを伝える |
| 保存していない変更を、知らせずに書き出しから落とす | 書き出す前に確かめる |
| 書き出しの失敗を、原因を見ずに「別の場所を選んで」と伝える | macOS が返した理由を添える |
| 読み込みの誤りの種類に、アプリ側の事情(一覧を変えられない)を足していた | プリセットの操作と同じ誤り(`PresetError.readOnly`)を使う |
| 読み込まなかった理由を、いつも「値が読めない」と書いていた | 「読み込めないプリセット」と書く |
| 同じファイルを2回読み込むと、全部が番号つきで重なる。取り消す手段がない | 直さない。利用者が決めた動き(一覧に足す。同じ名前には番号をつける)のとおり。`docs/TODO.md` に書いた |
