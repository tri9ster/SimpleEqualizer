- `design/AppIcon.svg`: 1024×1024。グラデーションの背景つき。アプリ用。

## 対応方針・作業手順

### `design/` の扱い

- `design/` は利用者が置いた元のデータとして扱う。Claude は読むだけで、書き換えない(`input/` と同じ扱い)。
- アプリに入れるファイルは、`design/` から写して作る。
- `design/` は Git に入れる(2026-10-12 決定)。`CLAUDE.md` の「構成」に書いてある。

### 手順

1. アプリにアセットカタログ(`Assets.xcassets`)を足す。
2. メニューバーのアイコン:
   - SVG をそのまま入れ、「テンプレート画像」として扱う設定にする。
     こうすると、明るい表示でも暗い表示でも、macOS が色を合わせる。
   - `MenuBarExtra` のアイコンを、これに差し替える。
3. アプリのアイコン:
   - アプリのアイコンは、決まった大きさの PNG の組が要る。SVG から書き出す。
   - 書き出しは、Apple 標準の仕組みだけで行う(外部のツールを入れない)。やり方は、着手時に試して決める。
   - 書き出しに使った手順(コマンドや小さなスクリプト)は、あとで作り直せるように `docs/` に残す。
4. ビルドして、アプリの中にアイコンが入っていることを確かめる。

## 実施結果

2026-10-12 に実施。利用者に見た目の確認を頼んだあと、問題の指摘はなく、コミットの指示を受けた。
個別の結果(明るい表示と暗い表示、Finder でのアイコン)は聞いていないので、TICKET-006 の確認に入れた。

行ったこと:

- アプリにアセットカタログ(`SimpleEqualizer/Assets.xcassets`)を足した。
- メニューバーのアイコン: `design/MenuBarIcon.svg` を写して入れ、テンプレート画像として扱う設定にした。
  ベクターのまま入るので、画面の細かさに関係なく、なめらかに出る。
- アプリのアイコン: `design/AppIcon.svg` から、7 種類の大きさ(16〜1024 ピクセル)の PNG を書き出した。
  書き出しは、小さな Swift のスクリプト(`tools/render-app-icon.swift`)で行う。Apple 標準の仕組み(AppKit)だけを使う。
- 加工していないときの警告の印(三角)は、macOS に入っている記号のままにした。

アイコンを直したときの手順:

1. `design/` の SVG を直す(利用者)。
2. アプリのアイコンは、PNG を作り直す。

   ```bash
   swift tools/render-app-icon.swift design/AppIcon.svg SimpleEqualizer/Assets.xcassets/AppIcon.appiconset
   ```

3. メニューバーのアイコンは、SVG を写し直す。

   ```bash
   cp design/MenuBarIcon.svg SimpleEqualizer/Assets.xcassets/MenuBarIcon.imageset/MenuBarIcon.svg
   ```

4. ビルドし直す。

確認できたこと(Claude):

- ビルドが通る(警告なし)。
- 書き出した PNG を目で見て、元のデザインどおり(グラデーションの背景、3本のスライダー、角の外側は透明)だった。
- できたアプリの中に、アプリのアイコン(`AppIcon.icns`)と、メニューバーのアイコン(ベクター)が入っている。
- `design/` の2つのファイルは、作業の前後で中身が同じ(ハッシュ値で確認)。
- `/code-review` の指摘はなかった。
