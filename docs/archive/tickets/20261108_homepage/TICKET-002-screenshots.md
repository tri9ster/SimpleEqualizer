# TICKET-002: 画面の画像を用意する

## 概要

ページに載せる画面の画像(ポップアップ、イコライザーのウィンドウなど)を、英語と日本語で用意する。
Claude は画面を見られないので、撮るのは利用者が行う。

- [x] 完了

## 依存関係

TICKET-001(どの画面を載せるか)

## 現状

2026-11-08 時点。ページに使える画面の画像はない。README のイラスト(`assets/readme/`。アプリの説明の図、システム設定、音量キー)は、ページでも使い回せる。

## 対応方針・作業手順

1. 撮る画面と撮り方を、利用者に手順で示す(TICKET-001 で決めた画面)。
   - 例: メニューバーのポップアップ、イコライザーのウィンドウ。英語と日本語で1枚ずつ。
   - ウィンドウだけを撮る(⌘⇧4 のあと Space を押し、ウィンドウを押す)。
2. 写っているものを確かめる。**特定の機材の名前(出力先の名前など)、個人の名前、プリセットの名前に個人的なものが写っていないこと**。
   出力先の名前が写る画面は、機材の名前が出ない出力先を選んでから撮ってもらう。
3. 画像を `site/images/` に置く。大きすぎるときは、`sips` で幅をそろえて小さくする。

## 影響ファイル

- `site/images/`(画像)

## 動作確認項目

- [x] 画像に、機材の名前や個人の情報が写っていない(利用者と Claude の両方で確かめる)。
- [x] ~~英語と日本語の画像がそろっている。~~ 英語の画像だけにした(2026-11-15、利用者の判断)。

## 実施結果

- 利用者が、イコライザーのウィンドウとポップアップを1枚に収めた画像を撮った(`assets/main_window.png`。英語の画面)。
- 画像は英語のものだけにする(2026-11-15、利用者の判断)。日本語のページでも、同じ画像を使う。
- 写っているものを確かめた(2026-11-15、Claude): イコライザー、ポップアップ(出力先は `USB SPDIF Adapter`、プリセットは `natural`)、
  メニューバー、日時、壁紙。特定の機材の名前と、個人の情報は写っていない。
  埋め込まれた情報は、「Screenshot」という説明と大きさだけ。
- 置き場所は、計画の `site/images/` ではなく `assets/`(README のイラストと同じく、`tools/build-site.sh` でページと合わせる)。
