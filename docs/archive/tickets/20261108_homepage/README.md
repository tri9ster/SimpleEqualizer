# ホームページ チケット一覧(2026-11-08)

GitHub Pages で、アプリのホームページ(紹介とダウンロードの案内)を作る。利用者の依頼(2026-11-08)。
アドレスは `https://tri9ster.github.io/SimpleEqualizer/` になる見込み。

- 無料のプランでは、非公開のリポジトリから GitHub Pages を使えない。ページは今のうちにブランチで作り、
  リポジトリを公開したあと(配布の TICKET-009)で有効にする。
- `docs/` は開発の記録に使っているので、ページのファイルは `site/` に置き、GitHub Actions で公開する(TICKET-001 で決めた)。
- 文言は、日本語と英語の両方を用意し、同じ内容にする。特定の機材の名前は書かない(README と同じ決まり)。

## 作業順序

```
TICKET-001 載せる内容と作り方を決める
    ├─ TICKET-002 画面の画像を用意する(利用者の作業が中心)
    └─ TICKET-003 ページを作る(英語と日本語)
           └─ TICKET-004 公開の仕組み(GitHub Actions)と README からの案内
                  └─ TICKET-005 GitHub Pages を有効にして確かめる(配布の TICKET-009 のあと)
```

- 001 を最初にする理由: 置き場所と作り方(手書きの HTML か、Jekyll か)で、003、004 のやり方が変わる。
- 002 と 003 は並べて進められる。画像がそろうまでは、003 では仮の枠を置く。
- 005 を最後にする理由: リポジトリを公開するまで、GitHub Pages を有効にできない。
