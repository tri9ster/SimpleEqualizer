# 段階5(仕上げ) チケット一覧(2026-10-13)

仕様書 11章の段階5にあたる。いまの出力先を加工する(仕様書 4.5)、音量キー(4.1、5.4)、
設定のウィンドウ(5.3)、ログイン時の起動(4.6)を作る。試作から残っている課題(サンプリング周波数の切り替え)も、ここで扱う。

## この段階でできるようになること

- macOS の出力先が何であっても、その音にイコライザーが掛かる(「Mac miniのスピーカー」など)。出力先を切り替えると、加工の対象も切り替わる。
- 音量調整は、出力先によって自動で有効・無効が決まる(自分で音量を変えられない装置では有効)。音量と消音は、出力先ごとに覚える。
- キーボードの音量キーで、アプリの音量を変えられる(音量調整が有効な出力先で)。
- 設定のウィンドウで、いまの出力先、音量キー、ログイン時の起動、許可の状態を見られる。
- ログイン時に、自動で起動できる。

## 範囲に入れないもの

- SONOS のネットワーク操作(案C)。第2段階の候補。
- アプリごとの音量調整、複数の出力装置を同時に扱うこと、周波数の波形表示、配布(仕様書 10章)。

2026-10-14 に、利用者の判断で、音量キーを先にした(音量キー → 出力先 → 設定)。チケットの番号は、作ったときのままにしてある。

```

TICKET-001 出力先まわりの調査(装置の一覧、音量を変えられるかの見分け方、切り替えの知らせ)
    └─ TICKET-002 出力先ごとの判断(音量調整の有効・無効など。テスト先行)
           └─ TICKET-003 いまの出力先を加工する(切り替えに追従する)
                  └─ TICKET-004 音量調整が無効の出力先の画面と、増幅したときの扱い
                         └─ TICKET-005 サンプリング周波数の切り替え
TICKET-007 設定のウィンドウと、ログイン時の起動
    └─ TICKET-008 実機での確認とまとめ
```

- 006 を最初にする理由: 利用者の判断。この時点では、対象は USB SPDIF Adapter だけで、音量調整はいつも有効なので、
  音量キーは、加工している間はいつもアプリが受け取る。
  「音量調整が無効な出力先では、キーを macOS に任せる」は、出力先を作るとき(TICKET-004)につなぐ。
- 001 を出力先の最初にする理由: 装置の見分け方と、切り替えにかかる時間を、作る前に確かめる。分かったことで、003 の作りが変わる。
- 007 を最後にする理由: 設定のウィンドウは、出力先と音量キーの状態を表示する。

「音を出すときの安全」の内容は、利用者が承知した(2026-10-14)。

### 1 の補足: 音量調整が無効の出力先での増幅

- 音量調整が無効の出力先では、アプリは音量を下げない。音量は、アプリの後ろで、装置(macOS の音量調整)が下げる。
  アプリの中を通る音は、いつも元の大きさなので、イコライザーで少しでも増幅すると、すぐに上限を超え、リミッターが働き続ける。
  リミッターが働き続けると、音がつぶれて聞こえる。
- 提案: **増幅した分だけ、全体を自動で下げる。** いちばん大きく上げているバンドが +6 dB なら、全体を 6 dB 下げる。
  - 音はつぶれない。そのかわり、イコライザーを入れると、全体が少し小さくなる。小さくなった分は、macOS の音量を上げてもらう。
  - 上げているバンドがなければ(下げるだけの設定なら)、何も下げない。
  - 音量調整が有効の出力先(USB SPDIF Adapter)では、これまでどおり、何もしない。
- 比べた案: 何もしない(リミッターに任せる)。作るものは減るが、内蔵スピーカーで増幅する設定を使うと、音がつぶれる。

利用者の決定(2026-10-14): 自動で下げる。はじめは入。**切にできる設定を置く。**
理由は、スピーカーごとに音量を合わせた状態で、音質の違いを聴き比べることがあるため
(自動で下げると、イコライザーを入・切したり、プリセットを切り替えたりしたときに、全体の大きさも変わってしまう)。

切にしたときに起きること(利用者に伝えた):

- 上げているバンドがあると、リミッターが働き、音がつぶれて聞こえることがある。音は割れず、上限も超えない。
  イコライザーのウィンドウに、「音を抑えています」と出る(段階3 で作った表示)。
- 設定を入から切にした瞬間に、下げていた分(最大で 10 dB)だけ、音が大きくなる。なめらかに変える。
  macOS の音量で変えられる出力先でのことなので、最大音量が出るわけではない。
- 設定は、出力先ごとではなく、アプリに1つとする。置き場所は、イコライザーのウィンドウ(下げているときの説明のそば)と、設定のウィンドウ。

### 2 の補足: ふだん使う出力先

- 動くことを確かめてあるのは、USB SPDIF Adapter(48 kHz / 2ch)だけである。
  仕様書 4.5: アプリが扱えない形式の出力先(動くことを確かめていないもの)では、音声に触らず、その旨を表示する。
- 利用者が実際に使う出力先を、確かめる対象にする。使わないものまで確かめると、手間が大きい。
- 教えてほしいこと: 「Mac miniのスピーカー」のほかに、使う出力先があるか(ディスプレイのスピーカー、Bluetooth のヘッドホンやスピーカー、AirPlay、ヘッドホン端子など)。
- TICKET-001 で、Claude が、この Mac につながっている出力先の一覧を調べる(音は出さない)。それを見てから決めてもよい。

## 音を出すときの安全(この段階での変更点)

この段階は、音の経路を、動いている間に作り直すようになる。これまででいちばん、大きな音が出るおそれに気をつける段階である。

- **出力先を切り替えた瞬間。** 経路を作り直す間、切り替え先の音が、加工なしで出るおそれがある。
  USB SPDIF Adapter へ戻したときに、最大音量が出るのが、いちばん危ない。
  TICKET-001 で、作り直しにかかる時間を測り、TICKET-003 で、対処を決める(確認を受けてから作る)。
- **初めて使う出力先の音量は 100。** 音量調整が有効な出力先(自分で音量を変えられない装置)を初めてつないだときは、
  アプリを使う前と同じ大きさ(最大)で音が出る。段階2 で決めた動きのとおり。
- **音量調整の有効・無効の見分けをまちがえたとき。**
  - 有効とまちがえると、音量が二重に掛かる(小さくなる側。危なくない)。
  - 無効とまちがえると、音量を変えられない装置で、アプリが音量を下げない(最大音量が出る。危ない)。
  - そこで、見分けられないときは、有効として扱う(TICKET-002)。
- **音量キー。** 音量キーをアプリが受け取っている間は、macOS の音量は変わらない。アプリが落ちると、キーは macOS に戻る。
- 音を試す直前には、毎回、スピーカー側の音量を下げてもらう。出力先を切り替える確認では、とくに。
