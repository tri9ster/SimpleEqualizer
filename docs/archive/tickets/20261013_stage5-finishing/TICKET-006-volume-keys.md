## 対応方針・作業手順

### 動き(仕様書 4.1)

- 音量を上げる・下げるキーは、1回で 1/16 ずつ変える。Option + Shift を押しながらだと、1/64 ずつ変える。
- 消音のキーは、消音を切り替える。
- キーを押したときは、音量の表示を、画面の下寄りに 1〜2 秒だけ出す(仕様書 5.4)。
- **音量調整が有効な出力先でだけ、アプリがキーを受け取る。** 無効な出力先では、キーに触らず、macOS に任せる。
  このチケットの時点では、対象は USB SPDIF Adapter だけ(音量調整はいつも有効)なので、加工している間は、いつも受け取る。
  無効な出力先の扱いは、TICKET-004 でつなぐ。
- 加工していないとき(切、失敗)も、キーに触らない。

### 許可

- キーを受け取るには、「アクセシビリティ」の許可が要る(仕様書 8章)。
- 許可がないときは、音量キーだけが使えない。ポップアップからの操作は使える。許可を求める案内と、設定を開くボタンを出す。
- 音量キーを使うかどうかの設定(初期値は有効)は、TICKET-007 の設定のウィンドウに置く。それまでは、いつも有効とする。

### 作り方

- キーの受け取りは、`CGEventTap`(仕様書 7章)。受け取る処理は、すぐに終わらせる(遅いと、macOS がキーの受け取りを止める)。
- 1回のキーで動かす量と、端で止まる計算は、音を出さずに確かめられるので、`Core/` に置いて、テストを先に書く。
- 着手時に、キーの受け取りを小さく試してから、作りを決める。

### 安全のための決まり

- 音量を上げるキーを押し続けても、100 で止まる(元の音量を超えない)。
- アプリが止まったり落ちたりしたら、キーは macOS に戻る。

### 作ったもの

- 音量キーの受け取り(`SimpleEqualizer/VolumeKeyTap.swift`)。上げる、下げる、消音の3つのキーを受け取り、macOS には渡さない。
- 押したときの表示(`SimpleEqualizer/VolumeHUD.swift`)。画面の下寄りの中央に、1.5 秒だけ出る。
- 1回のキーで動かす量の計算(`Core/` の `VolumeKey`)。テストを先に書いた。
- 「アクセシビリティ」の許可がないときは、ポップアップに、説明と「許可を求める…」を出す。
  許可が出ると、3 秒以内に、音量キーが効き始める(アプリを起動し直さなくてよい)。

### 動きの細かい決まり

- 刻みは、0〜100 を 16 に分けたもの(6.25 ずつ)。Option + Shift では、64 に分けたもの(約 1.56 ずつ)。
- スライダーで決めた、刻みの途中の音量(たとえば 30)からは、となりの刻みへ動く(上は 31.25、下は 25)。
- 消音しているときに、上げる・下げるを押すと、消音を解く(macOS 標準と同じ)。
- キーを押し続けると、上げる・下げるは続けて動く。消音は、押し続けても1回だけ切り替わる。
- アプリがキーを受け取るのは、加工している間だけ。加工を切っているとき、止まっているときは、キーに触らない。
- 音量キーで決めた音量は、端数になる(56.25 など)。ポップアップの数字は、四捨五入して出す(56)。

### `/code-review` の指摘と対処

| 指摘 | 対処 |
| --- | --- |
| 消音キーを押し続けると、消音が入ったり切れたりを繰り返す | 消音は、押し続けたときの繰り返しを受けつけない |

| 受け取りを外さずに捨てると、落ちる | 捨てる前に外す |
