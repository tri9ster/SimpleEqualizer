# TICKET-004: 音量調整が無効の出力先の画面と、増幅したときの扱い

## 概要

音量調整が無効の出力先(内蔵スピーカーなど)で、使えない操作を使えなくし、増幅したときに音がつぶれないようにする。

## 対応方針・作業手順

### 画面

- 音量調整が無効のとき、ポップアップの音量のスライダー、消音、ラウドネスは、使えない表示にする。
  理由を、短い文で出す(「この出力先の音量は、macOS の音量で変えます」のような文)。
- イコライザーとプリセットは、どの出力先でも使える。
- 出力先が変わったら、表示も変わる。音量と消音は、その出力先で覚えていた値を出す。

### 音量キー

- 音量調整が無効の出力先では、音量キーに触らず、macOS に任せる(TICKET-006 で作った受け取りに、判断をつなぐ)。

### 増幅したときの扱い(一覧の README の「1」。2026-10-14 に利用者が決めた)

- 音量調整が無効で、上げているバンドがあるとき、その分だけ全体を下げる。はじめは入。
  下げる量が変わるときは、音量と同じく、なめらかに変える。
- 下げていることを、イコライザーのウィンドウに出す(「音がつぶれないよう、全体を 6 dB 下げています」のような文)。
- **自動で下げるのを、切にできる設定を置く**(聴き比べのため)。置き場所は、イコライザーのウィンドウの、上の説明のそば。
  設定は、アプリに1つ(出力先ごとではない)。`state.json` に保存する。切り替えたときは、なめらかに変える。
  切のときは、リミッターが働くことがある(段階3 の「音を抑えています」の表示が出る)。

### TICKET-003 で、先に入れてあったもの

- 音量調整が無効の出力先では、ポップアップの音量、消音、ラウドネスを使えなくし、理由を出す。音量キーは、macOS に任せる。
- 増幅した分だけ、全体を自動で下げる(倍率の計算)。

### このチケットで作ったもの

- イコライザーのウィンドウに、「増幅した分だけ、全体を自動で下げる」のチェックを足した。音量調整が無効の出力先のときだけ出る。
  初期値は入。状態は `state.json` に保存する(項目は TICKET-002 で足してある)。
- チェックの下に、いまの様子を出す。
  - 下げているとき: 「音がつぶれないよう、全体を 6.0 dB 下げています。小さくなった分は、macOS の音量で上げてください。」
  - 切のとき: 上げているバンドがあると、音がつぶれて聞こえることがある、という説明。
  - 下げていないとき: その理由(上げているバンドがない、イコライザーが切、加工していない)。
- 音量調整が無効の出力先で、リミッターが働いているときの説明を、アプリの音量ではなく、ほかの直し方を案内する文にした。
- 切り替えたときは、倍率が、コールバックの中でなめらかに変わる(雑音は出ない見込み)。
