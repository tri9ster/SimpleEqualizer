# TICKET-001: 出力先まわりの調査

## 概要

いまの出力先を加工する(TICKET-003)を作る前に、装置の見分け方と、切り替えの知らせ方、切り替えにかかる時間を確かめる。
調べたことは `docs/research/` に残し、TICKET-002 以降の作りを決める材料にする。

## 現状

2026-10-13 時点。

- 加工の対象は、名前で探した「USB SPDIF Adapter」に固定してある(`AppModel.deviceName`)。
- 出力先を切り替えても、アプリは気づかない。USB SPDIF Adapter 用の経路を持ったままにしている。
- 利用者の実機では、切り替え、抜き差し、スリープのあとも、USB SPDIF Adapter に戻すと加工が続いた(試作、段階2、段階3)。

## 対応方針・作業手順

### 調べること

1. **この Mac の出力先の一覧。** 名前、UID、つなぎ方(内蔵、USB、Bluetooth など)、チャンネル数、サンプリング周波数、ストリームの本数。
2. **装置が自分で音量を変えられるかの見分け方。** Core Audio の、どの値を見れば分かるか。
   USB SPDIF Adapter(変えられない)と、「Mac miniのスピーカー」(変えられる)で、値が実際に違うことを確かめる。
3. **いまの出力先と、その変化の知らせ。** macOS のいまの出力先を知る方法と、変わったときに知らせを受け取る方法。
   抜き差し、スリープからの復帰のときに、どの知らせが、どの順で来るか。
4. **経路の作り直しにかかる時間。** タップ、集約装置、エンジンを作って始めるまでの時間。
   この間、切り替え先の音が、加工なしで出るおそれがある。
5. **サンプリング周波数の変化の知らせ**(TICKET-005 の下調べ)。

### 進め方

- 1 と 2 は、装置の情報を読むだけの小さなスクリプト(`tools/`)で調べる。**音は出さない。音声の経路にも触らない。**
  Claude が実行して、結果を記録する。
- 3 と 4 は、アプリに、調べるための記録(知らせを受けた時刻と種類、作り直しにかかった時間)を足して、利用者に操作してもらう。
  記録は、ポップアップに出すか、ファイルに書く。動きは変えない(対象は USB SPDIF Adapter のまま)。
- 結果を `docs/research/OutputDevices_Survey.md` にまとめ、TICKET-003 の対処(切り替えの瞬間の音)の案を、利用者に示す。

## 実施結果

2026-10-14 に調べた。結果は `docs/research/OutputDevices_Survey.md` にまとめた。

- 1、2(出力先の一覧、音量を変えられるかの見分け方): Claude が、スクリプト(`tools/list-output-devices.swift`)で調べた。音は出していない。
- 3、4(知らせ、経路を作る時間): アプリに記録を足し(`SimpleEqualizer/OutputResearch.swift`)、利用者に操作してもらった。
  記録は、ファイルから Claude が読んだ。
- 5(サンプリング周波数の変化の知らせ): 受け取る準備は入れたが、今回の操作では、周波数は変わらなかった。TICKET-005 で調べる。
- 利用者が聴いた結果(2026-10-14): 出力先を USB SPDIF Adapter に戻したときに、大きな音は出なかった。
  ケーブルを差し直したあとは、加工された音量で出た。スリープから復帰したとき、音に変化はなかった。
- 利用者の判断(2026-10-14): TICKET-003 は、案A(音量を変えられない装置の経路は、持ったままにする)で進める。

おもな結果:

- 3つの出力先(USB SPDIF Adapter、Mac miniのスピーカー、ディスプレイ)は、音の形が同じ。周波数は、内蔵スピーカーだけ 96 kHz。
- ディスプレイのスピーカーは、macOS から音量を変えられない(USB SPDIF Adapter と同じ扱いになる)。
- 経路を作り直すと、片付けと合わせて 150 ミリ秒ほどかかる。その間、加工なしの音が出る見込み。
- いまの作り(経路を持ったままにする)では、出力先でないあいだも、ケーブルを抜いているあいだも、コールバックが呼ばれ続け、
  戻した瞬間に切れ目がない。

調査用のコードは、TICKET-003 を作る間も使うので、残してある。TICKET-003 が終わるときに、要るものだけを残して消す。

| 指摘 | 対処 |
| --- | --- |
